<objective>
Implement index-based mesh element selection: `select_vertices_by_index`, `select_edges_by_index`, `select_faces_by_index`. This is the foundation of Milestone 2 — it resolves the README's documented "Selection is all-or-nothing" limitation and is a dependency for Phase 7 (baking needs face/UV-island targeting) and Phase 11 (scene dressing needs precise source/target selection).

Output: `validate_index_list` validator, a shared `_select_by_indices` handler helper plus three `handle_*` functions in the existing `addon/handlers/mesh_editing.py`, three `@mcp.tool()` functions appended to the existing `src/blend_ai/tools/mesh_editing.py`, and full test coverage at both layers (the handler layer has no existing test file for this module — this plan creates the first one).

See `.planning/phases/05-fine-grained-mesh-selection/05-RESEARCH.md` for the full technical rationale, especially the "Central architectural finding" in the Summary (why selection tools must leave the object in EDIT mode, unlike every other mesh_editing handler) and Pitfalls 1-4 (bmesh.from_edit_mesh vs bmesh.new(), update_edit_mesh, ensure_lookup_table, graceful invalid-index handling).
</objective>

         ```python
         def _select_by_indices(obj, indices, elem_type):
             """Enter edit mode and select only the given element indices.

             elem_type: 'VERT' | 'EDGE' | 'FACE'. Leaves the object in EDIT MODE
             with the selection applied — callers must NOT force it back to
             OBJECT mode (unlike every other handler in this file).
             """
             _select_only(obj)
             bpy.ops.object.mode_set(mode="EDIT")
             bpy.ops.mesh.select_mode(type=elem_type)
             bpy.ops.mesh.select_all(action="DESELECT")

             bm = bmesh.from_edit_mesh(obj.data)
             seq = {"VERT": bm.verts, "EDGE": bm.edges, "FACE": bm.faces}[elem_type]
             seq.ensure_lookup_table()

             max_index = len(seq) - 1
             selected, invalid = [], []
             for i in indices:
                 if 0 <= i <= max_index:
                     seq[i].select = True
                     selected.append(i)
                 else:
                     invalid.append(i)

             bm.select_flush(True)
             bmesh.update_edit_mesh(obj.data)
             return selected, invalid
         ```
       - Three new handlers (after `handle_select_linked`):
         ```python
         def handle_select_vertices_by_index(params):
             """Select specific vertices by index, leaving the mesh in edit mode."""
             obj = _get_mesh_object(params["object_name"])
             indices = params.get("indices", [])
             selected, invalid = _select_by_indices(obj, indices, "VERT")
             return {"object": obj.name, "selected": selected, "invalid": invalid, "mode": "EDIT"}

         def handle_select_edges_by_index(params):
             """Select specific edges by index, leaving the mesh in edit mode."""
             obj = _get_mesh_object(params["object_name"])
             indices = params.get("indices", [])
             selected, invalid = _select_by_indices(obj, indices, "EDGE")
             return {"object": obj.name, "selected": selected, "invalid": invalid, "mode": "EDIT"}

         def handle_select_faces_by_index(params):

             obj = _get_mesh_object(params["object_name"])
             indices = params.get("indices", [])
             selected, invalid = _select_by_indices(obj, indices, "FACE")
             return {"object": obj.name, "selected": selected, "invalid": invalid, "mode": "EDIT"}
         ```
